## Exercice 10 : Mini-application de gestion

Créez un script PHP complet (ou plusieurs fichiers) qui implémente les fonctionnalités suivantes :

**10.1** — `config.php` : fichier de configuration avec la connexion PDO (classe Database).

**10.2** — `models/ProductModel.php` : classe avec les méthodes :
- `getAll($page, $perPage)` — liste paginée des produits
- `getById($id)` — détail d'un produit avec catégorie, note moyenne et tags
- `search($keyword, $minPrice, $maxPrice)` — recherche avec filtres multiples
- `getTopSellers($limit)` — top des produits les plus vendus

**10.3** — `models/OrderModel.php` : classe avec les méthodes :
- `create($userId, $items)` — création de commande avec transaction
- `getByUser($userId)` — commandes d'un utilisateur avec détail des produits
- `updateStatus($orderId, $status)` — mise à jour du statut
- `getMonthlySales($year)` — chiffre d'affaires mensuel

**10.4** — `models/UserModel.php` : classe avec les méthodes :
- `register($data)` — inscription avec hachage du mot de passe
- `authenticate($email, $password)` — connexion sécurisée
- `getProfile($userId)` — profil avec statistiques (nb commandes, montant total, nb avis)

**10.5** — Un fichier `test.php` qui appelle chaque méthode et affiche les résultats pour vérifier que tout fonctionne.
